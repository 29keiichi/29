# エアコンクリーニングイチロー ホームページ

元のHP（みっちゃん本舗）と同じ仕組みで作った、エアコンクリーニングイチローのホームページのファイル一式です。
まだ公開前の下書きです。下の「残っている作業」を終えると公開できます。

## ファイルの説明（ざっくり）

| ファイル | 役割 |
|---|---|
| `index.html` | トップページ（お店の紹介・料金・お客さまの声） |
| `yoyaku.html` | ネット予約のページ |
| `links.html` | リンク集のページ（SNSのプロフィールなどから飛ばす用） |
| `menu.js` | 料金メニューのデータ。料金を変えるときはこのファイルだけ直せば、トップページと予約ページの両方に反映されます |
| `common.css` | 3ページ共通のデザイン |
| `images/` | 写真の置き場所（今は仮の絵が入っています） |
| `gas/Code.js` | 予約が入ったときに、スプレッドシートへの記録とメール送信を自動でやる仕組み（GAS）のプログラム |
| `gas/appsscript.json` | GASの設定ファイル |

## 残っている作業

### 1. 写真素材の差し替え

今 `images/` に入っているのは、ラベル入りの仮の絵（プレースホルダ）です。本物の写真が用意できたら差し替えてください。

- `images/ac-before.svg` … エアコンの作業前の写真
- `images/ac-after.svg` … エアコンの作業後の写真
- `images/owner.svg` … 店長の写真

差し替え方法は2通りあります。

- **方法A（写真をJPGで用意する場合）**：写真を `ac-before.jpg` / `ac-after.jpg` / `owner.jpg` という名前で `images/` に入れ、`index.html` と `links.html` の中の `.svg` の部分を `.jpg` に書き換える（作業事例の画像は `index.html` の script 内で `.svg` と書かれている場所も書き換える）
- **方法B（Museに頼む場合）**：写真をチャットで送って「HPの写真を差し替えて」と言えば、ファイル名の変更や書き換えはこちらでやります

作業事例を増やしたいときは、`index.html` の中の `CASES` というリストに1行足し、`images/` に `<名前>-before` / `<名前>-after` の写真を置きます。これもClaudeに頼めます。

### 2. GAS（予約の自動受付）の作成とデプロイ

今の状態では、予約フォームの送信先が仮の値（`yoyaku.html` の中の `GAS_URL = "TODO_ICHIRO_GAS_URL"`）になっているので、**このままでは予約は送信できません**。次の作業が必要です。

1. 予約を記録するGoogleスプレッドシートを用意する
2. そのスプレッドシートに紐づくGASプロジェクトを開き、`gas/Code.js` の内容を貼り付ける（`gas/appsscript.json` も設定として使う）
3. GASの画面で `setup()` という関数を1回だけ実行する（「予約一覧」「顧客台帳」のシートと見出しが自動で作られ、メール送信の許可を求められたら承認する）
4. GASを「ウェブアプリ」としてデプロイ（公開）する
   - 実行ユーザー：デプロイした本人
   - アクセスできるユーザー：全員（匿名ユーザーを含む）
5. デプロイすると `https://script.google.com/macros/s/……/exec` というURLが発行されるので、そのURLで `yoyaku.html` の `GAS_URL` を書き換える
6. 書き換えたら、テスト予約を1件入れて、スプレッドシートに記録されるか・確認メールが届くかを確認する

※手順3〜4は、Googleアカウントにログインした本人の操作が必要な場面があります。そのときは写真付きで順番に案内します。

### 3. GitHub Pagesでの公開

1. GitHubにこのHP用のリポジトリ（ファイルを入れる箱）を作る ※リポジトリの新規作成は本人の操作が必要です
2. このフォルダのファイル一式をリポジトリにアップロード（入れる）する
3. リポジトリの「Settings（設定）」→「Pages」で、公開するブランチ（main）を選んで保存する
4. しばらく待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` のアドレスで公開される
5. 公開されたら、トップページ・予約ページ・リンク集が開けるか、スマホで確認する
6. Googleマップのお店情報に、公開したHPのアドレスを登録する（任意）

### 4. 仮のままになっている情報の一覧

次の情報は仮で入れてあります。確定したら教えてください。こちらで差し替えます。

- **対応エリア**：横浜市・川崎市・横須賀市・藤沢市（仮）。予約フォームの市区町村プルダウンも横浜市18区＋川崎市7区＋横須賀市＋藤沢市＋「その他（ご相談）」で作ってあります
- **料金のオプション**：お掃除機能付きは「壁掛けとの合計で1台 17,250円」になるよう追加料金5,750円に設定。天井埋込・完全分解洗浄・室外機洗浄・消臭抗菌コートの料金が決まれば、メニューに追加できます（今は入れていません）
- **その他のクリーニング**：料金未定のため「その他のクリーニング・ご相談」という相談メニュー（0円・チェック式）だけ置いてあります
- **店長の紹介文**：仮の文章です。お名前や経歴を載せたい場合は教えてください
- **お客さまの声**：ユアマイスター評価4.91・口コミ156件のサマリーだけ表示し、個別の口コミ本文は載せていません
- **FAQ・ご予約の前の注意・キャンセル料**：元のHPの文章をそのまま仮置きしています。イチローの実際の運用と違う部分（支払い方法、キャンセル料、お引き受けできない機種など）があれば差し替えます
- **リンク集のスタッフ用リンク**：「準備中」表示にしてあります。顧客台帳スプレッドシートが決まったらリンクを設定します
- **受付時間の表示**：Googleマップの掲載情報どおり「毎日9:00〜21:00・定休日なし」で作ってあります
